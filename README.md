# Faiz Devfolio

A personal developer portfolio built with Flutter and Dart, designed to showcase professional experience, software projects, technical skills, and contact information.

## Overview

Faiz Devfolio is an Android portfolio application for presenting my software development background to potential employers and freelance clients.

The application uses a clean white interface with royal-blue accents and navigation for Home, Projects, Experience, and Contact.

## Features

- Home screen with professional introduction and skills
- Projects section with project descriptions and technology stacks
- Professional experience timeline
- Contact information and external profile links
- Responsive layouts for different screen widths
- Custom Android launcher icon and application branding
- Release APK build support

## Getting Started

### Prerequisites

Install the following tools:

- Flutter SDK
- Dart SDK (included with Flutter)
- Android Studio
- Android SDK
- Git

Verify your Flutter setup:

```bash
flutter doctor
```

### Run the Application

Clone the repository:

```bash
git clone https://github.com/faiziqbal1/faiz-devfolio.git
cd faiz-devfolio
```

Install dependencies:

```bash
flutter pub get
```

Check connected devices:

```bash
flutter devices
```

Run the application:

```bash
flutter run
```

### Build a Release APK

```bash
flutter build apk --release
```

The generated APK is located at:

```text
build/app/outputs/flutter-apk/app-release.apk
```
