# Faiz Devfolio

A responsive Flutter and Dart portfolio that presents my software development experience, selected project work, technical skills, and contact links.

## What’s included

- Responsive layouts for mobile and wider screens
- Home, Projects, Experience, and Contact sections
- Project summaries covering ERP systems, asset tracking, and e-invoicing
- Links to professional contact and profile pages

## Built with

Flutter · Dart · Material Design

## Run locally

Prerequisites: Flutter SDK and an available device, emulator, or desktop target.

```bash
git clone https://github.com/faiziqbal1/faiz-devfolio.git
cd faiz-devfolio
flutter pub get
flutter run
```

To build an Android release:

```bash
flutter build apk --release
```

## Project context

The project cards summarize areas of my professional experience. They are portfolio descriptions; this repository contains the portfolio application, not the underlying ERP or client systems.
